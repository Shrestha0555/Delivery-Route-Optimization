Delivery Route Optimizer

Delivery Route Optimizer is a smart delivery management system designed to calculate efficient delivery routes using Data Structures and Algorithms.

Project Objectives

  • Manage predefined delivery locations.
  • Find shortest distances between locations.
  • Optimize delivery sequence.
  • Reduce overall delivery distance.

Technologies Used

C++ Data Structures Dijkstra Algorithm HTML CSS JavaScript

Core Data Structures

  • Graph – Represents the road network.
  • Priority Queue – Used in Dijkstra's algorithm.
  • Queue – Manages pending deliveries.
  • Vector – Stores locations and distances.
